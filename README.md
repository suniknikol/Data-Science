# Neural Network Classification Project

## Project Overview
This project focuses on building and evaluating a Neural Network model for classification tasks.  
The goal was to compare its performance against other machine learning models and analyze its effectiveness.

## Data & Preprocessing
- Cleaned missing values and handled outliers  
- Feature selection and preprocessing were applied  
- Data was split into training and test sets  

##  Models Used
Several supervised learning models were implemented and compared:

- Logistic Regression  
- KNN  
- Decision Tree  
- Random Forest  
- Gradient Boosting  
- AdaBoost  
- XGBoost  
- SVM (Linear, Polynomial, RBF)  
- Neural Network (Final Model) 

## Neural Network
- Built using a multi-layer architecture  
- Trained on processed dataset  
- Tuned to reduce overfitting  

## Results
- Neural Network achieved the **best performance**
- Accuracy: ~0.92+  
- No significant overfitting observed  
- Outperformed most other models  

##  Model Comparison
The project includes a comparison between multiple models, highlighting:
- Accuracy differences  
- Model stability  
- Overfitting behavior

##  Conclusion
- Neural Networks provided the strongest results for this dataset  
- Model selection should always be validated through comparison  
- Filtering/preprocessing does not always improve results and must be tested
